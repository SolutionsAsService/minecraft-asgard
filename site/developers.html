Developers

Add a god, or a potion

The potions are data. The mod reads potions.json at startup, registers one ingredient item and one potion per entry, and adds the brewing recipe from Awkward Potion. An unknown effect id is logged and skipped.

One entry

{
  "id": "thors_valor",
  "name": "Thor's Valor",
  "god": "Thor",
  "epithet": "The Thunderer",
  "domain": "Storm and strength",
  "hue": "#3AB3DA",
  "realm": "asgard",
  "ingredient": "thunder_iron",
  "lore": "Thor's hammer rings in the forge. Strength for whoever strikes first.",
  "effects": [
    {
      "effect": "minecraft:strength",
      "seconds": 180,
      "amplifier": 1
    },
    {
      "effect": "minecraft:resistance",
      "seconds": 60,
      "amplifier": 0
    }
  ]
}
id
The potion’s path. The loader uses it to register the potion.
ingredient
The item path of the brewing ingredient. Each ingredient is one registry entry, so it must be unique.
effects
List of effect (a registry id such as minecraft:strength), seconds, amplifier (0 is level I).
name
Used by tools/gen_assets.py for the language file: the potion shows as "Potion of <name>" (and "Splash <name>", "Lingering <name>").
lore
One line for the ingredient’s tooltip (also written by the generator).
hue
Optional. The ingredient sprite’s colour. Without it the sprite takes the realm’s colour.
realm
A realm id from the realms list. The generator uses it for the default sprite colour.
god, epithet, domain
Optional. Used by this site; the mod ignores them.

Regenerate and build

python3 tools/gen_assets.py      # language file, item models, item definitions, sprites
gradle build
python3 _src/build_site.py       # this site

The loader and the data format are shared with the other Nordic Pantheon mods, built with the shadw-modding stack.

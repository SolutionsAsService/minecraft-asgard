Install Asgard

Asgard is a Fabric mod for Minecraft 1.21.4. No release jar is published yet, so you build it.

You need

  • Minecraft Java Edition 1.21.4 (not Bedrock)
  • Fabric, the mod loader: Fabric Loader 0.16 or later, and Fabric API
  • Java 21
  • Gradle 8, the build tool (the repository has no Gradle wrapper)

Build

git clone https://github.com/SolutionsAsService/minecraft-asgard
cd minecraft-asgard
gradle build
# the jar is in build/libs/asgard-0.2.0.jar

Copy the jar into your mods folder and start the game. The server log line Asgard loaded: 7 potions (6 from data, plus Blessing), 7 brewing recipes, 0 unknown effects skipped; 3 relics, 4 blocks confirms the registration.

Status

Builds on Fabric Loom 1.11.8 and Gradle 8. Loaded on a Fabric dedicated server for 1.21.4, and a client joined that server and showed the ingredients, potions, relics and structures (the screenshots on this site). Brewing in a stand, drinking the potions, using the relics and natural structure spawning are not yet tested.
